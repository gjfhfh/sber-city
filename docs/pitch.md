# Защита за 5 минут — «Город Сбера»

**0:00 — Проблема (30 с).** Для ребёнка банк — место, где «лежат деньги». На деле банк каждый день решает, кому дать кредит, когда покупать золото и как не потерять деньги вкладчиков. Учиться этому по учебнику скучно, а ошибаться на настоящих деньгах — дорого.

**0:30 — Решение (30 с).** «Город Сбера» — 3D-город в WebView СберKids. В центре главное здание Сбера, вокруг — отделы. Ребёнок полгода руководит отделом: читает новости и принимает решения.
Задача обучения: *после игры ребёнок умеет по новости определить, подорожает актив или подешевеет, и решает, когда рисковать, а когда — застраховаться.*

**1:00 — Живое демо в песочнице (2 мин).** Покрутить город → «Золото» → новость «На Камчатке нашли золото» → прогноз свайпом → разбор «почему» → решение «Заказ ювелиров» свайпом (видно, какие шкалы заденет) → «подождать» вниз → страховка → итог полугода → **здание перестраивается** → разбор решений → «Поделиться».

**3:00 — Почему это учит (40 с).** Предскажи → посмотри → объясни. Оценка решения, а не удачи: повезло без причины — башни не будет. Немедленное объясняющее «почему» вместо «неверно». Наблюдаемый результат: «новостей прочитано верно X из Y» и стиль банкира.

**3:40 — Почему это поедет в приложение (40 с).** Чистый HTML/CSS/JS, WebGL 1, ≈ 240 КБ из 5 МБ. Ноль внешних запросов, ноль новых разрешений, ноль бэкенда. Используются только пять событий контракта. Контент — JSON, можно положить на CDN: новые новости, отделы и вероятности без релиза. Битый JSON не ломает игру.

**4:20 — Что дальше (40 с).** Ещё четыре отдела-острова — это только JSON-колоды. Озвучка для младших. Связка со статьями «Контента».
